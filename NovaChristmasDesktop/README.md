# Nova Christmas Desktop

Новогодний оверлей для Windows 10/11 x64: падающий снег, хвойные гирлянды сверху и снизу экрана, мерцающие разноцветные лампочки.

## Запуск

Скачайте готовый архив из **Actions → последняя успешная сборка → Artifacts → NovaChristmasDesktop-Windows-x64**. Распакуйте ZIP и запустите `NovaChristmasDesktop.exe`.

Значок приложения появится возле часов Windows. Нажмите по нему правой кнопкой мыши, чтобы включить/выключить снег и гирлянды или закрыть приложение.

Приложение собирается как self-contained single-file EXE — .NET Runtime на целевом ПК не нужен.
